# 视觉设计

本文档说明站点的视觉设计：气质、字符格、颜色、字体，以及它们在代码里的位置。改样式前先读这里；改了设计就同步更新这里。

相关文档：[`architecture.md`](architecture.md)（文件职责）、[`decisions.md`](decisions.md)（每个选择的取舍，这一版设计是 D35–D39、D41–D47）。

## 1．气质

**首要原则是阅读舒适。** 任何设计上的取舍——颜色、字体、装饰——和阅读舒适冲突时，都让位于它。

这一版的视觉语言取自 [lewish.io](https://lewish.io/)，一句话：**把网页当成一块终端屏幕来排。** 全站一种等宽字，所有间距落在「一个字符格」上，没有任何装饰；层次只靠语法高亮式的颜色来分——标题是绿色，日期是红色，链接是蓝色。

为了首要原则，有三处没有照搬原站（理由见 D36）：

| 原站 | 本站 | 原因 |
| --- | --- | --- |
| 行高 24px（字号的 1.33 倍） | 行高 30px（1.67 倍） | 原站排的是英文；一行四十多个汉字，1.33 倍太挤，试过 1.5 倍仍偏密 |
| 亮色下链接 `#4489c2`、行内代码 `#2d82af` | `#3973a3`、`#2978a1` | 原色对页面底的对比度只有 3.53 和 4.02，不到 4.5 |
| 暗色下日期 `#f07178dd`（带透明度） | `#f07178`（不透明） | 原色对比度 3.93 |

## 2．字符格

18px 的 Inconsolata 一个字符正好宽 9px，一个汉字（系统黑体）宽 18px，占两格，所以中英文混排也能对齐。

| token | 值 | 含义 | Tailwind 类名示例 |
| --- | --- | --- | --- |
| `--spacing-cw` | `0.5rem`（9px） | 一个字符的宽度，横向间距的单位 | `gap-cw` |
| `--spacing-line` | `calc(5rem / 3)`（30px） | 一行的高度，纵向间距的单位 | `mb-line` |

**规则：横向间距只用 `--spacing-cw` 的倍数，纵向只用 `--spacing-line` 的整数倍或一半。** 带线的元素把线宽算进格子（代码块的 1px 描边、引用块的 2px 竖线），所以 `global.css` 里会出现 `calc(… - 1px)` 这样的写法。

根字号写成 `112.5%` 而不是 `18px`，读者在浏览器里调大字号时整个格子跟着放大。

| 项目 | 值 |
| --- | --- |
| 内容栏 | 最大宽度 800px，居中，内边距半行 × 两个字符（文字区 764px，一行约 42 个汉字；手机上两侧各留 18px）。放不下的长串（长网址）在中间断开，不撑宽页面 |
| 段落 | 上下各空一行 |
| 列表 | 上下各空一行，左右各一个字符，左内边距三个字符 |
| 标题 | 行高两行（h4 一行）；正文里的 h2–h4 上方再空一行，紧跟它的元素不留上外边距，所以标题离上文远、贴着下文 |
| 断点 | 只有一个：1300px，只影响文章页的目录 |
| 圆角、阴影、渐变、过渡、页脚 | 全部没有 |

## 3．颜色

所有颜色都是语义 token，定义在 `src/styles/global.css` 的 `@theme` 里，写成 `light-dark(亮色, 暗色)`。

**规则：组件里只用 token，不直接写色号，也不用 Tailwind 的原始色和 `dark:` 变体。每种颜色有固定的角色，不能拿来随意强调文字**——比如不能用红色去强调一句话。

| token | 亮色 | 暗色 | 角色 |
| --- | --- | --- | --- |
| `--color-page` | `#fdf7f5` | `#292d3e` | 页面底 |
| `--color-surface` | `#e2dbd8` | `#242736` | 代码块底 |
| `--color-body` | `#2e2c2d` | `#d8e0ec` | 正文、代码块描边 |
| `--color-muted` | `#676e95` | `#8f96b8` | 次要文字：文章页的日期行（日期本身除外）和摘要、脚注、内部滚动条 |
| `--color-strong` | `#2e2c2d` | `#fffefe` | 加粗文字、表头、主题切换链接、提示块标题 |
| `--color-green` | `#5c9e56` | `#62de84dd` | h1 |
| `--color-h2` | `#563cb1` | `#ffcb6bdd` | h2（亮色紫、暗色黄） |
| `--color-cyan` | `#1a7575` | `#60baec` | h3、行内代码。亮色偏青绿，和链接蓝拉开 |
| `--color-blue` | `#3973a3` | `#75a1ff` | 链接、引用线、页面滚动条、焦点框 |
| `--color-red` | `#aa4f28` | `#f07178` | 日期 |
| `--color-purple` | `#563cb1` | `#f580ffdd` | 列表符号 |
| `--color-yellow` | `#a78c2c` | `#ffcb6bdd` | Warning 提示块的竖线、高亮文字的底色（30% 浓度） |

### 明暗主题

首次访问跟随系统的明暗设置。页头右上角的主题切换链接显示的是「要切到的那个主题」的名字（`light` 或 `dark`），点击后把选择写进 `localStorage`，以后的访问沿用。

实现：`src/layouts/Base.astro` 里有两段内联脚本，一段在 `<head>` 里把存下来的选择写到 `<html data-theme>` 上（在页面画出来之前，避免闪一下），一段处理点击。`global.css` 根据 `data-theme` 设 `color-scheme`，所有 `light-dark()` 跟着它走，所以 token 不需要写两套。脚本没运行时切换链接不出现，页面照常跟随系统。

### 界面语言

**界面文字一律用英文**：站名、首页简介、「Posts」、日期行的「N min read」和「updated」、页头的链接、给读屏软件的标签。文章的标题、摘要、正文、标签是用什么语言写的就是什么（目前是中文），不翻译。没有语言切换。

### 对比度

按 WCAG 2 的公式计算（带透明度的颜色先叠到页面底上）。正文类文字要求不低于 4.5:1，大号粗体（标题）要求不低于 3:1。

| 前景 | 背景 | 亮色 | 暗色 |
| --- | --- | --- | --- |
| 正文 | 页面 | 13.07 | 10.26 |
| 加粗文字 | 页面 | 13.07 | 13.55 |
| 正文 | 代码块底 | 10.14 | 11.13 |
| 次要文字 | 页面 | 4.67 | 4.69 |
| 链接 | 页面 | 4.77 | 5.39 |
| 行内代码、h3 | 页面 | 5.15 | 6.32 |
| 日期 | 页面 | 5.13 | 4.77 |
| 列表符号 | 页面 | 7.40 | 4.97 |
| h2 | 页面 | 7.40 | 7.23 |
| h1（只用于大号粗体） | 页面 | 3.06 | 6.39 |
| Warning 黄（只画线，不承载文字） | 页面 | 3.08 | 7.23 |

亮色下的 h1 绿只够大号文字的标准，**不要把 `--color-green` 用在正文字号的文字上**。代码高亮的颜色来自 Shiki 主题，用测试长文里出现的全部颜色实测过：两套主题下对代码块底都不低于 4.5:1（两个注释色是在 `global.css` 里换过的，见下）。

改色值后要重新算一遍。

### 代码高亮

Shiki 双主题：亮色 `github-light-high-contrast`、暗色 `material-theme-palenight`（在 `astro.config.mjs` 里配置）。亮色不用普通的 `github-light`：它是为白底设计的，压在 `--color-surface` 上关键字只有 3.35:1。两套主题的注释色仍然不够（亮 3.68、暗 2.99），在 `global.css` 里按色值匹配着换掉了；**换主题后要重新核对那两条规则**。暗色主题选 Palenight，是因为这套配色本来就出自它，页面底色 `#292d3e` 就是它的背景色。token 颜色用主题自带的，**底色不用主题自带的**，统一成 `--color-surface`。

## 4．字体

| 用途 | token | 字体 | 来源 |
| --- | --- | --- | --- |
| 正文、标题、界面文字（西文） | `--font-body` | Inconsolata（可变字重） | npm 包 `@fontsource-variable/inconsolata`，随站点一起部署 |
| 正文、标题、代码里的汉字 | `--font-body`、`--font-mono` 的第二项 | 霞鹜文楷（LXGW WenKai，开源楷体），常规和粗体两个字重；字体没到时先显示系统黑体 | npm 包 `lxgw-wenkai-webfont`，随站点一起部署 |
| 代码块、行内代码 | `--font-mono` | Source Code Pro（可变字重），0.9rem（16.2px） | npm 包 `@fontsource-variable/source-code-pro`，随站点一起部署 |

- 破折号和省略号（`——`、`……`）单独指给霞鹜文楷：Inconsolata 里也有这两个字形，排在前面会把它们画成贴着基线的西文样子。做法见 `global.css` 顶部的 `CJK Punct`。
- 行内代码和按键的字号是所在文字的 0.9 倍（`em`），在标题里跟着标题放大。
- 西文全是同一种等宽字，汉字全是同一种楷体（代码里的西文除外）。字重只有 400（正文）和 700（标题、加粗、表头），霞鹜文楷这两个字重都是真字形，不是合成的。
- 霞鹜文楷按 `unicode-range` 切成上百个分片，浏览器只下载页面上实际用到的字所在的分片；字体没到时先显示系统黑体（`font-display: swap`）。两份样式表在 `src/layouts/Base.astro` 里作为单独的文件放在 `<body>` 末尾，不并进主样式表：它们的 `@font-face` 列表各有一百多 KB，并进去会挡住首屏渲染。
- 斜体只用于文章页的摘要。Inconsolata 和霞鹜文楷都没有真正的斜体字形，是浏览器把正体倾斜出来的。
- 字号只有四级，全部字重 700：h1 32px 绿色，h2 28.57px，h3 22.68px 青色，h4 18px 正文色。**标题不要比 32px 更大**——层级靠颜色区分，不靠大小。

## 5．各处的样式约定

元素的样式都写在 `global.css` 的 `@layer base` 里，对全站生效，所以页面和组件里几乎不需要写类名。

- **页头**：右上角一行右对齐的纯文字链接，之间隔一个字符：主题切换、`projects`、`twitter`、`github`、`rss`（`projects` 和 `rss` 是站内页面，在当前标签页打开；`twitter`、`github` 的地址在 `src/site.config.ts` 里）。`book` 和 `design` 两个站（D48）挪到了 `/projects/` 页，页上每个项目是纯文字的终端写法，没有图片，见 D50。文章页左上角多一个返回链接 `< ozine`（`site.name`）。窄屏放不下时，右侧整组链接换到下一行并保持右对齐，链接本身不折断。没有标志、导航条和分隔线。
- **首页**：h1 站名 `ozine.me`（首页标题和浏览器标签页用 `site.title`；返回链接用短名字 `site.name`，显示为 `< ozine`），一段简介，h2「Posts」，然后每篇三行：h3 标题链接；一行「红色日期 / N min read」；一段摘要。这里都是正文色、正体。条目之间没有分隔线也没有卡片。
- **文章页**：h1 标题，同样的日期行（多显示更新日期和 `#标签`，都是次要文字色的纯文字），摘要（次要文字色、斜体），目录，正文。正文之后是两行纯文字链接：`reply via email`（打开邮件，主题预填「Re: 文章标题」）和 `twitter`；再下一行是返回链接 `< ozine`。这是文章的收尾，不是全站页脚，首页没有。
- **链接**：蓝色，带下划线，访问过的颜色不变，没有悬停效果。例外：h3 标题链接和目录链接没有下划线。
- **标题锚点**：正文里每个 h2、h3 后面隔一个字符跟一个 `#`，是指向自己的链接。由 `src/plugins/heading-anchor.ts` 生成，`#` 字符由 CSS 画出。
- **列表**：无序列表的符号是 `">  "`（一个大于号加两个空格），紫色加粗；有序列表用数字，正文色。任务列表不画 `>`，复选框就是符号。
- **目录**：视口宽度 1300px 以上时固定在内容栏左侧、右对齐，内容栏右移 100px 给它让位；以下是正文开头的一个普通 `>` 列表，三级标题多缩进两个字符。二级标题的条目加粗。窗口宽度跨过 1300px 时目录会进出正文，文章页有一小段脚本把读者眼前的段落滚回原位，画面不会跳（D45）。
- **代码块**：页面上唯一的盒子。底色比页面深一档，1px 正文色描边，直角。行内代码只变青色，没有底色和描边。
- **引用**：左侧 2px 蓝色竖线。
- **提示块（Callout）**：和引用同一个样子，类型只体现在竖线的颜色上（note 蓝、tip 绿、warning 黄、danger 红、important 紫、quote 正文色）；标题是加粗的正文，不上色。没有底色。
- **表格**：没有任何线；表头加粗、用加粗文字色（不用蓝色，免得像链接）；列之间只靠四个字符的右内边距隔开；行之间空半行。默认左对齐，Markdown 里写了 `:---:`、`---:` 的列按写的对齐。单元格不折行，放不下时整张表横向滚动——所以长句子不要放进表格。
- **公式**：构建时用 KaTeX 渲染，是页面上唯一的衬线字，字号是正文的 1.1 倍。行内公式嵌在文字里，不撑高所在的行；块级公式居中，上下各空一行（一半是内边距，给上下标留地方），放不下时自己横向滚动。公式的样式写在 `global.css` 的 `@layer base` 之外，且 KaTeX 的样式表要先于 `global.css` 引入，否则盖不过 KaTeX 自带的值。
- **高亮**（Obsidian 的 `==文字==`）：一层淡黄色的底，文字颜色不变。这是「不用底色块」的唯一例外。
- **按键**（`<kbd>`）：加粗的代码字体，前后由样式加上方括号，像 `[Ctrl]`，不画键帽。
- **脚注**：正文里是蓝色的上标数字，内容在文章末尾的编号列表里，次要色，和正文之间空两行；文章末尾的回复链接再和它隔开两行。脚注区的标题只给读屏软件，页面上不显示，也不进目录。
- **折叠内容**（正文里直接写的 `<details>`）：上下各空一行，没有边框。
- **分隔线**（Markdown 的 `---`）：不画线，只空出一行。
- **图片**：占满内容栏宽度，没有描边、圆角和阴影。
- **滚动条**：宽 18px，滑块是直角方块，四周留 7px。页面的滚动条是蓝色；代码块、表格、公式自己的横向滚动条是次要色，免得一条蓝线被读成分隔线。只对 Chrome、Safari、Edge 生效，Firefox 用系统默认的。
- **键盘焦点**：2px 蓝色外框。

## 6．动效

没有。没有过渡、入场动画和悬停动画，主题切换是瞬间完成的，所以也不需要处理「减弱动态效果」。

## 7．禁忌

- 不用第二种字体排正文或标题。
- 不用圆角、阴影、渐变、底色块、卡片、分隔线。带描边的只有代码块，带底色的只有代码块和高亮文字。
- 不用图标、标志、插画、头图。网站图标（浏览器标签页上的）是例外。
- 不加过渡和动画。
- 不用不在格子上的间距。
- 不居中文字，不两端对齐。一切左对齐，只有页头链接和悬浮目录右对齐。
- 不做导航条、首屏大图、页脚。

## 8．角色图

`pic/` 里的角色图（`logo.png`、`character.png`）是上一版设计用的：首页头像和右下角的看板娘。这一版不用插画，页面上不再出现它们；文件和生成脚本保留，将来想用可以直接引入。`pic/favicon.svg`（旧角色的头像图标）也不再使用。

网站图标是 `pic/favicon.png`（192×192）：站长的头像，从本机的原图裁出头部和肩上的猫那一块再缩小——整张图缩到标签页的 16px 会认不出来。四角裁成圆角（半径约为边长的 22%），圆角外是透明的。原图不在仓库里；换图标时重新裁一张同名的 PNG 覆盖即可。

`pic/original/` 是站长的个人素材，只留在本机，不进入公开仓库。

## 9．怎么改

| 想改什么 | 改哪里 |
| --- | --- |
| 某个颜色 | `src/styles/global.css` 的 `@theme`，改完重新核对对比度，并更新本文档第 3 节的表 |
| 行高（想回到原站的 24px） | `global.css` 的 `--spacing-line`，改成 `calc(4rem / 3)`；1.5 倍是 `1.5rem` |
| 字体 | `global.css` 的 `--font-*`，以及 `src/layouts/Base.astro` 里引入的字体包 |
| 代码高亮主题 | `astro.config.mjs` 的 `shikiConfig.themes` |
| 公式的字号、间距 | `global.css` 的 `.katex`、`.katex-display` |
| 页头的链接 | `src/layouts/Base.astro` |
| 界面文字 | 直接写在用到它的组件里；站名和首页简介在 `src/site.config.ts` |
| GitHub、Twitter 地址、回复邮箱、站名、简介 | `src/site.config.ts` |

`design/preview.html` 是上一版紫灰配色定稿前的探索稿，和现在的站点没有关系，保留作历史记录。
