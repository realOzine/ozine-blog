light-dark() 与一套不需要 JavaScript 的明暗主题

2026-08-15 · CSS 设计 Astro

长时间阅读时，最先让人疲劳的往往不是字号，而是对比度。纯黑的字压在纯白的底上，边缘会显得过于锐利；把两端都往中间收一点，文字就安静下来了。这一段用来检查正文的灰度、行高，以及一个正文里的链接看起来是否突兀。

语义 token 而不是色号

组件里不应该出现 stone-100 这样的原始色，而应该写 var(--surface)。这样换一套配色只需要改一处，明暗两版也由同一个变量承担。

/* 每个 token 同时声明亮色与暗色 */
:root {
  color-scheme: light dark;
  --bg:     light-dark(#faf9fc, #16141c);
  --accent: light-dark(#6d4fc2, #b9a8f0);
}

export function contrast(a: number, b: number) {
  const [hi, lo] = a > b ? [a, b] : [b, a];
  return (hi + 0.05) / (lo + 0.05); // "AA" 要求 ≥ 4.5
}

Note

普通说明。蓝灰色，饱和度压低，不和链接抢注意力。

Tip

建议与技巧。偏灰的青绿色。

Warning

需要留意的地方。琥珀色，是整页唯一的暖色。

Danger

会出问题的操作。偏玫瑰的红色。

Important

重点。改用梅红色，避开紫色，免得被当成链接。

Quote

引文。直接用次要文字的灰。
